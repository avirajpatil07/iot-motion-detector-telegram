# IoT Motion Detector with Telegram Alert

## Project Description
This project detects motion using a PIR sensor and sends a Telegram message using ESP32 in Wokwi simulation.

## Components Used
- ESP32
- PIR Sensor
- LED
- Telegram Bot
- Wokwi Simulator

## Working
When motion is detected:
- LED turns ON
- Telegram alert is sent

## Platform
- Wokwi
- Arduino Code
- Telegram Bot API
